📖 이 게시판의 역할 (준비 중)
HKMC ALC 코드집 변환: HKMC에서 받은 열별 ALC 코드집(FRT LH/RH · RR BACK LH/RH · RR CUSH)을 DYA 통합 ALC2 마스터(ALC코드 집 생성용) 형식으로 변환합니다.

DYA ALC2 코드 5자리 구성 규칙

  • ICE(기본차): [지역코드][원단코드][생성순서 2자리][차종코드] — 예: AA01J
  • HEV: [생성순서 2자리][지역코드][원단코드][차종코드] — 예: 01AAJ
📷 생산기술팀 배포 "SP3 차종 ALC2 CODE 조합(예시)" 캡처 기준. 원단/지역 코드 매핑표(원단 및 지역 코드 엑셀)가 확보되면 자동 변환 로직이 완성됩니다.

📖 이 게시판의 역할 (준비 중)
DYA ALC-2 코드 생성: [HKMC Q파트 & ALC 이력 관리]에 등록된 Q파트 종합 + 열별 ALC 5종을 읽어, 각 생산 행의 KEY02~KEY06 코드를 조합(예: 572J+629J+6LRJ+Y19J+7KTJ → 572J629J6LRJY19J7KTJ)하고 통합 ALC2 마스터에서 대응하는 DYA ALC-2 5자리 코드(예: JL16F)를 찾거나 신규 생성합니다.
💡 처리 순서: ① Q파트 종합 로드 → ② KEY01 국가코드 해석(국가코드 마스터 HKMC 열) → ③ KEY02~06 → 20자리 KMC ALC-2 → ④ 마스터 대조 → 기존이면 재사용 / 신규면 규칙대로 채번 → ⑤ 결과 엑셀 다운로드.
