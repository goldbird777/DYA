PEL = Product Equipment List (제품 사양 목록) — 고객사(HKMC 등)가 차량의 옵션·사양을 정의하는 부품 코드 체계입니다.
📖 사용 설명서 — 신입사원용 (클릭하여 접기/펼치기)
이 게시판은? 고객사의 PEL 코드와 그에 대응하는 DYA 품번·사양을 짝지어 놓은 기준표입니다.

어디에 쓰이나요?

[HKMC PEL(부품사양서) → DYA E-BOM] 게시판에서 부품사양서를 올리면, 이 표를 참조하여 자동으로 표준 BOM을 생성합니다. 이 표에 코드가 없으면 자동 생성 시 누락되므로 항상 최신으로 유지해야 합니다.

사용 방법

  1. 상단 검색창으로 코드·사양·설명을 찾습니다.
  2. 표의 칸을 클릭해 바로 수정하면 자동 저장됩니다.
  3. [+ 신규 행]으로 코드를 추가하고, [엑셀 일괄 업로드]로 전체를 교체합니다.
🔒 편집은 관리자만 가능하며, 엑셀 일괄 업로드는 기존 데이터를 전부 교체하니 주의하세요.
