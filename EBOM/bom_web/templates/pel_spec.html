이 게시판은? HKMC 부품사양서(원본 PEL)를 올리면 PEL CODE 마스터를 읽어 사양수현황 그리드(●)로 자동 변환해 보여줍니다. 표준 BOM 변환 전, 사양을 한눈에 확인·검토하는 게시판입니다.

사용 방법

  1. 상단 차종 선택 → 그 차종의 사양변경 리비전 이력이 열립니다.
  2. [✍️ 글쓰기]로 부품사양서 파일을 올리면 자동 변환됩니다. (파워트레인은 파일에서 자동 인식)
  3. [그리드 보기]로 사양수현황을 확인하고, 기본차/환경차 필터로 영업이 원하는 사양만 볼 수 있습니다.
💡 열(옵션) 구성은 PEL CODE 마스터의 옵션그룹·표시순서로 자동 결정됩니다. 차종마다 열이 달라도 마스터만 관리하면 됩니다. 다운로드는 사양수현황(●) 엑셀 또는 원본을 받을 수 있습니다.
