이 게시판은? HKMC에서 받는 Q파트 종합(생산계획)과 열별 ALC 코드집 5종(FRT LH/RH · RR BACK LH/RH · RR CUSH)을 차종별로 한 게시글에 묶어 이력 관리하고, DYA ALC-2 코드를 생성합니다.

사용 순서

  1. 기준 마스터 3종을 아래에서 한 번 등록합니다(교체 전까지 계속 사용).
  2. 차종 선택 → [✍️ 글쓰기]로 6개 파일(Q파트 종합 + ALC 5종)을 첨부해 등록합니다.
  3. 등록된 게시글의 [⚙️ ALC-2 생성]을 누르면 판정 + O·X 통합코드집이 생성됩니다.
💡 변환 결과물은 「★통합 ALC2 코드_REV」 형태로 만들어집니다. 즉 표준 마스터(MES OX표기용)로 기존코드를 매칭하고, 열별 사양 마스터와 PEL CODE 마스터로 옵션 O·X를 채워, 최종 산출물 서식(★REV)으로 내보냅니다. 6개 파일만 올리면 됩니다.
📚 기준 마스터 3종 (ALC-2 생성 기준 · 한 번 등록) 교체 전까지 모든 생성에 사용됩니다
