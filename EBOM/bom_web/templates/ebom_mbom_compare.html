⚖️ E-BOM & M-BOM 비교 {{ me.username }} ({{ me.role }})
📖 이 게시판의 역할
E-BOM 1레벨 품번(10자리)과 M-BOM(HKMC ALC 코드집)의 CCC 제외 10자리 품번을 대조하고, 같은 품번에 대해 설계가 적은 사양과 생관이 적은 사양이 일치하는지 검증합니다. PEL CODE 마스터를 공통 기준으로 사용합니다(예: 5693A3 = T & P = SIDE AIR BAG).

판정은 «축» 단위입니다

사양은 원단·에어백·헤드레스트처럼 종류(축)별로 묶이고, 각 축에서 값은 하나만 고릅니다. 축은 PEL CODE 마스터의 옵션그룹입니다. 축별로 나눠 보는 이유는, 사양 전체를 통째로 비교하면 표기 세밀도 차이(USB ↔ USB(27W)) 때문에 정상인 것도 전부 불일치로 나오기 때문입니다.

비고란 읽는 법 — 고칠 곳이 다릅니다

  • 불일치 — 양쪽 값이 실제로 어긋남 → BOM 파일 또는 ALC 확인
  • 보완필요(마스터) — E-BOM에 용어는 있는데 PEL 마스터에 없음 → PEL CODE 마스터 설명란에 별칭 추가
  • 보완필요(E-BOM) — E-BOM N열에 그 축이 아예 없음 → E-BOM 파일 N열 확인
💡 설계(OPT1/2/3)와 생관(COMBI) 양식 차이는 PEL CODE 마스터의 설명란에 쉼표로 별칭을 추가해 흡수합니다. 사양·기본 설명은 바꾸지 않습니다. S/HTR·V/HTR·MNL은 PEL 사양이 아니라 판정에서 제외합니다.
