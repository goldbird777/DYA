CCC = Color Combination Chart (색상 조합표)

이 게시판은?

차종별로 재질(CLOTH · A/CL 콤비 · A/LE 인조 · P/L 천연)과 국가코드별 CCC 3자리 컬러 코드를 정의합니다.

사용 방법

  1. 상단에서 차종과 단계를 선택합니다.
  2. 매트릭스의 각 칸(재질 × 국가)에 CCC 코드(예: A7A, BQ6)를 입력합니다.
  3. [💾 저장]을 누릅니다.
💡 여기서 정의한 CCC 코드는 [영업 단가 입력] 게시판에서 자동으로 불러와집니다. 차종마다 코드가 다르므로 반드시 차종별로 관리하세요.
차종 🔗 차종 기준 관리 (단계 무관 — 최신값이 현재 배색)
🎨 CCC 컬러 코드 매트릭스 (재질 × 국가코드)
사용법: 재질별 · 국가코드별 CCC 3자리 코드를 직접 입력하세요. (예: A7A, BQ6, C12)
여러 원단(경우의 수)이 있는 칸은 쉼표(,)로 구분해 함께 입력하세요. (예: AGF, 방오원단, 방오C)
국가코드 추가/수정은 국가코드 관리 페이지에서 가능합니다. 차종별로 다른 CCC 코드를 정의하면 영업단가 입력에서 자동으로 필터링됩니다.
차종과 단계를 선택하면 매트릭스가 표시됩니다.
